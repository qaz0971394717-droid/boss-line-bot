# 個人備忘機器人

獨立 Worker `hongzhe-personal-memo`、獨立 D1 `hongzhe-personal-memo`。僅接受已設定本人 LINE ID 的一對一私訊，其他使用者、群組及一般聊天不存檔、不回覆。不建立 LINE 推播或計時排程。

- `備忘 內容`、`備忘列表`、`查備忘 關鍵字`
- `待辦 內容`、`待辦`、`今天待辦`（包含逾期與未指定日期項目）
- `提醒 明天 15:00 事項`；日期可用今天、明天、後天、YYYY-MM-DD
- `查看 編號`、`文字 編號`、`完成 編號`、`取消完成 編號`、`刪除 編號`

提醒儲存在 LINE 備忘 DB 後，仍須自行點擊加入 Google 日曆並儲存。日曆連結不具 OAuth 存取權限，無法確認事件是否已儲存，也無法設定通知時間或同步更新。請在 Google 日曆設定預設通知（例如提前 10 分鐘）及允許 Android 通知。重複儲存同一連結可能產生重複日曆事件。

私密設定全部透過 GitHub Actions Secrets：`MEMO_LINE_CHANNEL_ACCESS_TOKEN`、`MEMO_LINE_CHANNEL_SECRET`、`MEMO_OWNER_LINE_USER_ID`；共用 Cloudflare 部署授權，沒有共用 LINE 金鑰或資料表。擁有者 ID 缺漏時保持鎖定。

webhook 先驗簽再授權；event ID 持久化去重；不確定執行狀態不會重播寫入。若寫入成功但回覆儲存失敗，事件保留 pending，需要人工核對。沒有公開資料讀取端點，Google 日曆 URL 只在本人回覆內產生。

備份及資料保留：備忘不自動刪除；刪除動作採軟刪除。每天驗證 D1 SQL 備份至私人 R2 後，清除超過 14 天已送達 event（保留未完成），清除超過 30 天軟刪除資料。R2 日常備份保留 30 天。Google 日曆屬使用者自身帳號，與備份分開。

## Google 日曆直接新增（需要額外 Google 授權設定）

設定 GitHub Secrets `MEMO_GOOGLE_CLIENT_ID`、`MEMO_GOOGLE_CLIENT_SECRET` 後重新部署。OAuth 用戶端類型為網頁應用程式，精確重新導向 URI：

`https://hongzhe-personal-memo.qaz0971394717.workers.dev/google/callback`

只申請 `https://www.googleapis.com/auth/calendar.app.created`。LINE 私訊「連結日曆」產生 10 分鐘單次使用連結；驗證 state、相同瀏覽器 HttpOnly Cookie 及 PKCE 後交換授權。專用日曆由程式建立，不讀取其他既有日曆。Refresh token 使用 AES-GCM 加密，金鑰只保存在這個 Worker 的 secret。資料庫或 R2 備份不含解密金鑰；若 Worker 金鑰遺失，須重新授權 Google。請勿覆寫 GOOGLE_TOKEN_KEY。

Google 專案若為 External + Testing，refresh token 一般會在 7 天後失效。個人正式使用前需適當設定 Google Auth Platform 的發布狀態，依 Google 要求完成所需設定；失效時提示重新連結，不假裝新增成功。

完成連結後「確認新增至日曆」會以固定事件 ID 寫入專用日曆，提前 10 分鐘 popup；成功收到回應才確認。逾時重試先查同事件 ID，避免重複新增。不會自動匯入舊資料、不會通知其他參與者、不會發送 LINE 推播。已用手動連結存入 Google 的舊提醒不受程式管理，請勿再次用直接新增按鈕重複加入。

完成備忘不會同步修改 Google 事件。提醒卡片只保留新增與刪除；刪除可選只刪備忘、備忘與日曆一起刪、取消。一起刪除只允許刪除記錄中對應的程式事件，核對私有識別及日曆 ID；Google 操作失敗時保留備忘。程式不會自行新增測試行程；需要使用者點選確認新增。

## 彈性輸入格式

可直接輸入「提醒 明天下午3點要去考HPE6 A85考試」「明天下午三點提醒我拿包裹」「下週一早上9點開會」「10分鐘後提醒我買牛奶」。也接受 10/20 下午3:30、2026/10/20 09:30、10月20日中午12點、中文數字與全形數字。下週一以台灣時間的下個週一計算；無年份的日期採今年，已過期時請補年份，不會自動跳到明年。

未指明上午／下午的「明天3點」會要求澄清。24 小時制 03:00、15:00 可直接使用；缺日期、時間或事項時不新增資料。只支援明確的常見句型，不是任意中文 AI 理解。重複提醒未開放。辨識後先顯示小卡，仍須本人按確認才寫入 Google 日曆。

備忘接受「幫我記一下買牛奶」「筆記 買牛奶」「備忘買牛奶」，搜尋接受「搜尋牛奶」「找筆記牛奶」。「今天有什麼事」可查待辦。未來不到 10 分鐘的提醒改為開始時間通知，避免提前通知時間已過；其他提醒仍預設提前 10 分鐘。
